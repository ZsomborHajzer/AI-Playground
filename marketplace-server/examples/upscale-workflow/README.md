# Upscale 4x

Adds an Image Edit workflow that enlarges an image 4x with the RealESRGAN x4plus model.

- The model (about 65 MB) is downloaded the first time you run the workflow, after you confirm.
- It installs one pinned ComfyUI custom node, `evanspearman/ComfyMath`, which is why the plugin
  asks for the "Run programs" permission.

This is an example plugin from the AI Playground plugin authoring guide.
